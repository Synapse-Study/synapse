Step 3 — API Keys & Anki Setup

Configure your free Gemini keys for Lecture Notes & AI Tutor, optional Notion sync, and verify AnkiConnect.

Google Gemini API Keys (Free Tier)
Why two keys? Google AI Studio gives each separate project its own daily free quota (20 requests/day for Gemini 4 Hydrogen / 3.8 Flash, and 1,500 requests/day for Flash Lite). Creating two projects doubles your quota and ensures lecture notes never exhaust your AI tutor quota!
  1. Open Google AI Studio: Click and sign in with any Google account (100% free, no credit card needed).
  2. Create Key 1 (Lecture Notes): Click the blue "Create API key" button → select "Create API key in new project" → name it Synapse Notes → copy the key and paste into the Gemini API Key — Lecture Notes box below.
  3. Create Key 2 (AI Tutor): Click "Create API key" again → select "Create API key in new project" → name it Synapse Tutor → copy the key and paste into the Gemini API Key — AI Tutor box below.

Notion Workspace Integration (Optional)
  1. Create Integration: Open and click "+ New integration".
  2. Copy the Secret Token: Name it Synapse, select your Notion workspace, click "Save", and copy the Internal Integration Secret (starts with secret_... or ntn_...). Paste it into the Notion Secret Key box below.
  3. Connect to your Page / Database: Open your target page or database in Notion → click the ••• (three dots) in the top-right corner → click "Connect to" or "Add connections" → select your Synapse integration.
  4. Copy the Page ID: Copy the 32-character ID from your Notion browser URL and paste it into the Notion Database / Page ID box below.
Anki Desktop & AnkiConnect Add-on Port 8765
Crucial: The Anki desktop application must be open and running in the background for Synapse to sync flashcards and test the connection.
  1. Open Anki: Launch the Anki desktop application on your Mac.
  2. Open Add-ons Menu: In Anki's top menu bar, click Tools → Add-ons (or press Cmd + Shift + A).
  3. Install AnkiConnect: Click the "Get Add-ons..." button in the bottom right corner of the Add-ons window.
  4. Enter Code: Paste code 2055492159 into the code box and click OK.
  5. Restart Anki: Quit and reopen Anki so the new add-on starts running.
  6. Verify Connection: Leave Anki open in the background, then click "Test AnkiConnect" below.
